# Введение
**LOLAutomationTools** — это инструмент расширения функций для **"League of Legends"**; он используется, чтобы помочь игрокам выполнить некоторые простые клиентские операции, чтобы сэкономить небольшое количество времени в некоторых сценах, где они не могут освободить руки или должны временно уйти; программное обеспечение не будет слишком сильно мешать пониманию игроком и игровому процессу игры, поэтому некоторые функции все равно необходимо настраивать вручную (например, настройка рун героя). Слишком большая сдержанность заставит людей оцепенеть и потеряет удовольствие от самой игры; Играйте активно и весело, чтобы создать гармоничную среду.

## Автопик
Прежде чем использовать **Выбрать героя** и **Отключить героя**, вам необходимо выполнить операции редактирования на странице конфигурации (кнопка за элементом переключателя).

Предметы героев, добавленные в настройках ветки, действуют только в некоторых режимах игры с *предварительно выбранными позициями* (например, *Квалифицированный* и *Экстремальный блиц*), случайные эффекты действуют только в режимах *Случайный герой* (например, *Дуги*, *Бесконечная потасовка*, страница случайной конфигурации не включена в конфигурацию отключенного героя) и, как правило, действительны во всех других режимах (за исключением перечисленных ранее режимов, это сделано для целей использования). При выполнении автоматического выбора героя герой будет выбран в соответствии с **Выбор героев**. Элементы конфигурации выбираются сверху вниз.

## Предпик
Логика выполнения этой функции в основном такая же, как и у **Выбрать героев**. Разница в том, что **Предварительно выбранные герои** будут действовать только в режимах с отключенными этапами, таких как *Квалифицированный* и в некоторых развлекательных режимах, требующих отключенных героев.

## Автобан
Страница конфигурации **Отключить героя** по сути аналогична странице конфигурации **Выбрать героя**. Только есть кнопка переключения режимов в правом верхнем углу. Нажмите кнопку, чтобы переключиться в отключенный режим.

*Обычный режим бана*: Логика работы этого режима соответствует странице конфигурации **Выбора героев**. При выполнении автоматического бана героев, если отключенный герой не настроен, игрок будет забанен через 0 секунд оставшегося времени фазы бана.

*Режим отключения группы*: элементы в списке конфигурации будут заменены соответствующими героями в конфигурации **Выбор героев**. Выбрав предмет, дважды щелкните элемент героя слева, чтобы добавить его в **Отключить группу** героя. При автоматическом отключении героя будет соблюдаться порядок элементов конфигурации **Выбрать героев**. Если в **Группе отключения** всех конфигураций **Выбора героев** нет героев, которых нужно отключить, они будут отключены в соответствии с логикой обычного режима запрета.

>Если включен параметр *Игнорировать предварительный выбор товарища по команде*, обнаружение предварительного выбора команды будет пропущено при выполнении автоматического бана героя. Не рекомендуется включать эту опцию.

## Автопринятие
Автоматически принимать совпадение после сопоставления.

>Если включена опция *Отложить принятие совпадений*, функция **Принять совпадения** автоматически примет совпадение только тогда, когда останется последняя секунда обратного отсчета принятия.

## Создать лобби
Вы можете создать совпадение вручную с помощью кнопки **Создать совпадение** или включить этот переключатель, чтобы создать совпадение автоматически.

>*Автоматически создавать игру* Вам необходимо выбрать игровой режим, который вы хотите создать, в *Дополнительных настройках*, этот параметр не будет сохранен в конфигурации.

## Найти игру
Автоматический поиск совпадений. Это вступит в силу только в том случае, если вы находитесь в комнате режима матча и являетесь владельцем команды (организатором).

>Если опция *Обнаружение тайм-аута* включена, совпадения будут автоматически повторно найдены в очереди совпадений, если оценка очереди превышает указанный интервал.

## пропускать комплименты
Пропустите страницу похвалы товарища по команде в конце игры.

## Пропустить конец игры
Пропустите ожидание расчета в конце игры (загрузка черного экрана в кружках) или страницу послематчевого расчета и вернитесь в комнату игрового режима.

## Обмен
Содержит основной элемент переключателя и три независимых элемента переключателя. Также необходимо выполнить другие настройки. В дополнительных настройках **Функции обмена** укажите, следует ли обмениваться героями с товарищами по команде в режиме случайных героев или обмениваться этажами (порядком выбора героев) и предварительно выбранными слотами с товарищами по команде в режиме найма.

*Настройка смены героев и смены позиций относительно проста, поэтому я не буду здесь вдаваться в подробности. *

<img width="900" height="680" alt="image" src="https://github.com/user-attachments/assets/361b4b19-cd72-4cb3-901f-69d49284bc11" />

В разделе **Дополнительные настройки** раздела **Этажи обмена** вы можете установить порядок обмена (т. е. этажи) и режим обмена.

<img width="900" height="680" alt="image" src="https://github.com/user-attachments/assets/697bed4a-2984-43f6-b747-36c7911ef99d" />

*Режим обмена*:
- Только целевой порядок: принимайте запросы от товарищей по команде, соответствующие указанному *порядку*.
- Содержит целевой приоритет: принимать запросы от товарищей по команде в пределах указанного *порядка*.
- Приказ отсрочки с целью: принимать запросы от товарищей по команде ≥ указанного *порядка*.
- Объем на основе целевого порядка: принимает запросы от товарищей по команде с *порядком* ≤ (*указанный порядок* - *объем*) и *порядок* ≥ (*заданный порядок* + *объем*).

Кроме того, в разделе **Другие настройки** есть два варианта обмена отказами. Когда эти два параметра включены,** если товарищ по команде просит вас обменять героев или выбирает позицию, которая не соответствует определенным условиям, запрос на обмен будет автоматически отклонен. **В противном случае** никаких действий предпринято не будет. Вы можете решить, принимать ли обмен.

## Защита от доджа при пике/бане
Если эта функция включена, команды **Выбрать героя** или **Отключить героя** будут выполняться в последнюю секунду фазы BP.

>Вы можете изменить настройки режима функции **Запретить возврат выбранных героев** на *Странице настроек функции*.

## Ответы при отсутствии
Этот элемент переключателя является основным, и вам необходимо выполнить другие настройки. На странице конфигурации **Дополнительно** укажите, следует ли автоматически отвечать на сообщения друзей или приглашения в игру при выходе (они включены по умолчанию), а также задайте текстовое содержимое ответа.

## Автозакрытие игры
Простой и понятный, игровой процесс автоматически закрывается, когда в конце игры воспроизводится анимация окончания кристалла.

## Автореконнект
Попытайтесь переподключиться, когда игре потребуется переподключение.

## Автокарта (расширение)
Если герой в данный момент в игре является мастером карт, используйте клавиши Z/X/C для автоматического выбора синих/красных/желтых карт.

![pickCards](https://github.com/user-attachments/assets/df5aa45a-8593-44c9-8c3f-bec315552113)

>Эта функция реализована с помощью графической обработки и симуляции клавиатуры. Он тестирует только два часто используемых разрешения (1920x1080/2560x1440). Другие разрешения невозможно использовать без самостоятельной настройки (особенно разрешения, отличные от коэффициента масштабирования 16:9). Обнаружение допускает определенный диапазон фильтра, но рекомендуется не включать фильтр при использовании этой функции, чтобы не сделать определенное обнаружение недействительным.

## Быстрый старт

### 1. Подготовьте хостер
Загрузите `LOLAutomationTools` (≥ 2.9.801) со [страницы исходной версии] (https://github.com/Seraph1ne/LOLAutomationTools/releases) и извлеките ее в любой каталог, который будет записан как `<宿主目录>` ниже.
Этот репозиторий **не распространяет** хост-программы.

### 2. Загрузите модель речи
VoiceModule требует модель ASR в формате sherpa-onnx (около 254 МБ). Этот репозиторий **не распространяет** модель. Адрес загрузки и структуру каталога см. в [voice-module/README.md → Загрузка модели](voice-module/README.md#模型下载).

### 3. Установка в один клик.
Выполните (PowerShell) в корневом каталоге этого хранилища:
```powershell
.\scripts\install.ps1 -HostDir <宿主目录> -ModelDir <解压好的模型目录>
```
Параметры:
```powershell
-WithOpgg -SeraphineDir <Seraphine 目录>    # 同时安装 OP.GG launcher
-VoiceZip <本地 zip>                          # 离线安装，跳过下载
```
Скрипт автоматически: Загрузит Release `VoiceModule-latest.zip` → Остановит хост → Скопирует dll/pdb → Запишет `exe.config` (существует без перезаписи) → Поместит конфигурацию по умолчанию в `Extend/` (уже существует без перезаписи) → Скопирует модель.

### 4. Включить
Запустите `LOLAutomationTools.exe` → **Расширенные функции** слева → **Группировка голоса** → Включите переключатель **Голос в текст**. Нажмите и удерживайте `空格`, чтобы говорить, отпустите, чтобы отправить сообщение в командный чат.
