# บทนำ
**LOLAutomationTools** เป็นเครื่องมือขยายฟังก์ชันสำหรับ **"League of Legends"**; มันถูกใช้เพื่อช่วยให้ผู้เล่นดำเนินการบางอย่างกับไคลเอนต์ง่ายๆ เพื่อประหยัดเวลาเล็กน้อยในบางฉากที่พวกเขาไม่สามารถปล่อยมือหรือจำเป็นต้องออกไปชั่วคราว ซอฟต์แวร์จะไม่รบกวนความเข้าใจและการเล่นเกมของผู้เล่นมากเกินไป ดังนั้นฟังก์ชั่นบางอย่างยังจำเป็นต้องกำหนดค่าด้วยตนเอง (เช่น การกำหนดค่ารูนฮีโร่) ความยับยั้งชั่งใจมากเกินไปจะทำให้ผู้คนมึนงงและสูญเสียความสนุกของเกมไป เล่นอย่างแข็งขันและมีความสุขเพื่อสร้างสภาพแวดล้อมที่กลมกลืนกัน

## เลือกแชมเปียนอัตโนมัติ
ก่อนที่จะใช้ **เลือกฮีโร่** และ **ปิดการใช้งานฮีโร่** คุณต้องดำเนินการแก้ไขในหน้าการกำหนดค่า (ปุ่มด้านหลังรายการสวิตช์)

ไอเท็มฮีโร่ที่เพิ่มในการตั้งค่าสาขาจะมีผลเฉพาะในโหมดเกมบางโหมดที่มี *ตำแหน่งที่เลือกไว้ล่วงหน้า* (เช่น *เข้าเกณฑ์* และ *Extreme Blitz*) การสุ่มจะมีผลเฉพาะในโหมด *ฮีโร่สุ่ม* เท่านั้น (เช่น *Arcs*, *Infinite Brawl* หน้าการกำหนดค่าแบบสุ่มไม่รวมอยู่ในการกำหนดค่าฮีโร่ที่ปิดใช้งาน) และโดยทั่วไปจะใช้ได้ในโหมดอื่น ๆ ทั้งหมด (ยกเว้นโหมดที่ระบุไว้ก่อนหน้านี้ นี่เป็นเพื่อประโยชน์ของข้อกำหนดการใช้งาน) เมื่อทำการเลือกฮีโร่อัตโนมัติ ฮีโร่จะถูกเลือกตาม **เลือกฮีโร่** รายการการกำหนดค่าจะถูกเลือกจากบนลงล่าง

## เลือกล่วงหน้า
ตรรกะการดำเนินการของฟังก์ชันนี้โดยพื้นฐานแล้วจะเหมือนกับ **เลือกฮีโร่** ข้อแตกต่างก็คือ **ฮีโร่ที่เลือกไว้ล่วงหน้า** จะมีผลเฉพาะในโหมดที่มีด่านที่ปิดใช้งาน เช่น *ผ่านการคัดเลือก* และโหมดความบันเทิงบางโหมดที่ต้องใช้ฮีโร่ที่ถูกปิดใช้งาน

## แบนแชมเปียนอัตโนมัติ
หน้าการกำหนดค่า **ปิดใช้งานฮีโร่** โดยพื้นฐานแล้วจะเหมือนกับหน้าการกำหนดค่า **เลือกฮีโร่** มีเพียงปุ่มเปลี่ยนโหมดอยู่ที่มุมขวาบนเท่านั้น คลิกปุ่มเพื่อสลับไปยังโหมดปิดใช้งาน

*โหมดแบนปกติ*: ตรรกะการทำงานของโหมดนี้สอดคล้องกับหน้าการกำหนดค่าของ **เลือกฮีโร่** เมื่อทำการแบนฮีโร่โดยอัตโนมัติ หากไม่มีการกำหนดค่าฮีโร่ที่ถูกปิดการใช้งาน ผู้เล่นจะถูกแบนใน 0 วินาทีของเวลาที่เหลือของช่วงการแบน

*โหมดปิดการใช้งานกลุ่ม*: รายการในรายการการกำหนดค่าจะถูกแทนที่ด้วยฮีโร่ที่เกี่ยวข้องในการกำหนดค่า **เลือกฮีโร่** เมื่อเลือกรายการ ให้ดับเบิลคลิกรายการฮีโร่ทางด้านซ้ายเพื่อเพิ่มลงใน **กลุ่มปิดการใช้งาน** ของฮีโร่ เมื่อปิดใช้งานฮีโร่โดยอัตโนมัติ ลำดับของรายการการกำหนดค่าของ **เลือกฮีโร่** จะตามมา หากไม่มีฮีโร่ที่จะปิดการใช้งานใน **กลุ่มปิดการใช้งาน** ของการกำหนดค่า **เลือกฮีโร่** ทั้งหมด ฮีโร่เหล่านั้นจะถูกปิดการใช้งานตามตรรกะของโหมดแบนปกติ

>หากเปิดใช้งาน *ละเว้นการเลือกเพื่อนร่วมทีมล่วงหน้า* การตรวจหาการเลือกทีมล่วงหน้าจะถูกข้ามไปเมื่อทำการแบนฮีโร่อัตโนมัติ ไม่แนะนำให้เปิดใช้งานตัวเลือกนี้

## ยอมรับอัตโนมัติ
ยอมรับการแข่งขันโดยอัตโนมัติหลังจากจับคู่แล้ว

>เมื่อเปิดใช้งานตัวเลือก *หน่วงเวลายอมรับการแข่งขัน* **ยอมรับการแข่งขัน** จะยอมรับการแข่งขันโดยอัตโนมัติเมื่อเหลือวินาทีสุดท้ายของการนับถอยหลังการยอมรับเท่านั้น

## สร้างห้อง
คุณสามารถสร้างการแข่งขันได้ด้วยตนเองผ่านปุ่ม **สร้างการแข่งขัน** หรือเปิดสวิตช์นี้เพื่อสร้างการแข่งขันโดยอัตโนมัติ

>*สร้างเกมโดยอัตโนมัติ* คุณต้องเลือกโหมดเกมที่คุณต้องการสร้างใน *การตั้งค่าเพิ่มเติม* ตัวเลือกนี้จะไม่ถูกบันทึกลงในการกำหนดค่า

## ค้นหาเกม
ค้นหาการแข่งขันโดยอัตโนมัติ สิ่งนี้จะมีผลเมื่อคุณอยู่ในห้องโหมดการแข่งขันและคุณเป็นเจ้าของทีม (เจ้าบ้าน)

>หากเปิดใช้งานตัวเลือก *การตรวจจับการหมดเวลา* การจับคู่จะถูกค้นหาอีกครั้งโดยอัตโนมัติในคิวการจับคู่ หากการประมาณคิวเกินช่วงเวลาที่ระบุ

## ข้ามคำชมเชย
ข้ามหน้าสรรเสริญเพื่อนร่วมทีมเมื่อสิ้นสุดเกม

## ข้ามสรุปผล
ข้ามการรอการชำระเมื่อสิ้นสุดเกม (หน้าจอสีดำโหลดเป็นวงกลม) หรือหน้าการชำระบัญชีหลังการแข่งขัน และกลับสู่ห้องโหมดเกม

## แลกเปลี่ยน
ประกอบด้วยรายการสวิตช์หลักและรายการสวิตช์อิสระ 3 รายการ คุณต้องทำการตั้งค่าอื่นๆ ด้วย ในการตั้งค่าเพิ่มเติม **ฟังก์ชันการแลกเปลี่ยน** ให้ตั้งค่าว่าจะแลกเปลี่ยนฮีโร่กับเพื่อนร่วมทีมในโหมดฮีโร่แบบสุ่มหรือแลกเปลี่ยนชั้น (ลำดับที่เลือกฮีโร่) และช่องที่เลือกไว้ล่วงหน้ากับเพื่อนร่วมทีมในโหมดรับสมัคร

*การตั้งค่าการสลับฮีโร่และตำแหน่งการสลับค่อนข้างง่าย ดังนั้นฉันจะไม่ลงรายละเอียดที่นี่ *

<img width="900" height="680" alt="image" src="https://github.com/user-attachments/assets/361b4b19-cd72-4cb3-901f-69d49284bc11" />

ใน **การตั้งค่าเพิ่มเติม** ของ **ชั้น Exchange** คุณสามารถกำหนดลำดับการแลกเปลี่ยน (เช่น ชั้น) และโหมดการแลกเปลี่ยนได้

<img width="900" height="680" alt="image" src="https://github.com/user-attachments/assets/697bed4a-2984-43f6-b747-36c7911ef99d" />

*โหมดการแลกเปลี่ยน*:
- คำสั่งซื้อเป้าหมายเท่านั้น: ยอมรับคำขอจากเพื่อนร่วมทีมที่สอดคล้องกับ *คำสั่งซื้อ* ที่ระบุ
- มีลำดับความสำคัญเป้าหมาย: ยอมรับคำขอจากเพื่อนร่วมทีม ≤ *คำสั่ง* ที่ระบุ
- คำสั่งเลื่อนโดยมีเป้าหมาย: ยอมรับคำขอจากเพื่อนร่วมทีม ≥ *คำสั่ง* ที่ระบุ
- ขอบเขตตามลำดับเป้าหมาย: ยอมรับคำขอจากเพื่อนร่วมทีมที่มี *คำสั่ง* ≤ (*คำสั่งที่ระบุ* - *ขอบเขต*) และ *คำสั่ง* ≥ (*คำสั่งที่ระบุ* + *ขอบเขต*)

นอกจากนี้ ยังมีตัวเลือกการแลกเปลี่ยนการปฏิเสธอีก 2 ตัวเลือกใน **การตั้งค่าอื่นๆ** เมื่อเปิดใช้งานทั้งสองสิ่งนี้** หากเพื่อนร่วมทีมขอแลกเปลี่ยนฮีโร่กับคุณหรือเลือกตำแหน่งที่ไม่อยู่ในเงื่อนไขที่กำหนด คำขอแลกเปลี่ยนจะถูกปฏิเสธโดยอัตโนมัติ **มิฉะนั้น** จะไม่ดำเนินการใดๆ คุณสามารถตัดสินใจได้ว่าจะยอมรับการแลกเปลี่ยนหรือไม่

## กันหนีตอนเลือก/แบน
เมื่อเปิดใช้งานสิ่งนี้ **เลือกฮีโร่** หรือ **ปิดการใช้งานฮีโร่** จะถูกดำเนินการในวินาทีสุดท้ายของช่วง BP

>คุณสามารถเปลี่ยนการตั้งค่าโหมดของฟังก์ชัน **แบนการป้องกันการกลับมาของฮีโร่ที่เลือก** ได้ใน *หน้าการตั้งค่าฟังก์ชัน*

## ตอบกลับตอนไม่อยู่
รายการสวิตช์นี้เป็นสวิตช์หลัก และคุณต้องทำการตั้งค่าอื่นๆ ในหน้าการกำหนดค่า **เพิ่มเติม** ให้ตั้งค่าว่าจะตอบกลับข้อความเพื่อนหรือคำเชิญเล่นเกมโดยอัตโนมัติหรือไม่เมื่อออกไป (ซึ่งเปิดใช้งานตามค่าเริ่มต้น) และตั้งค่าเนื้อหาข้อความของการตอบกลับ

## หน้าต่างเสริม
เมื่อเปิดใช้งาน **หน้าต่างเพิ่มเติม** จะแสดงขึ้นในระหว่างบางเฟสของไคลเอ็นต์ นอกจากนี้ คุณสามารถคลิกปุ่มด้านหลังสวิตช์นี้เพื่อเข้าสู่ **หน้าการกำหนดค่า** ของ **หน้าต่างเพิ่มเติม** ซึ่งคุณสามารถดู **คุณสมบัติสมดุล** (ถ้ามี) ของฮีโร่ในโหมดความบันเทิงที่มีอยู่ในปัจจุบัน และกำหนดค่าการกำหนดค่ารูนและการกำหนดค่าที่ไม่ขึ้นอยู่กับไคลเอนต์ที่มีให้ใช้งานในแต่ละโหมด

**หน้าต่างเพิ่มเติม** หน้าการกำหนดค่า</br>

>หากคุณต้องการเพิ่มหรืออัปเดตการกำหนดค่ารูนของฮีโร่บน **หน้าการกำหนดค่ารูน** คุณจะต้องเลือกหน้ารูนใน **คอลเลกชัน - รูน** ในไคลเอนต์เกม แก้ไขและบันทึก เปลี่ยนทักษะซัมมอนเนอร์จากมุมขวาบน แล้วกดปุ่ม **เพิ่มการกำหนดค่า** หรือปุ่ม *อัปเดตการกำหนดค่าเกมปัจจุบันเป็นการกำหนดค่านี้* ใน **รายการการกำหนดค่ารูน** ที่จะอัปเดตเพื่อเพิ่มหรืออัปเดตการกำหนดค่ารูน

## ปิดเกมอัตโนมัติ
เรียบง่ายและตรงไปตรงมา กระบวนการของเกมจะปิดโดยอัตโนมัติเมื่อมีการเล่นแอนิเมชั่นตอนจบแบบคริสตัลเมื่อสิ้นสุดเกม

พยายามเชื่อมต่อใหม่เมื่อเกมจำเป็นต้องเชื่อมต่อใหม่

## เลือกไพ่อัตโนมัติ (ส่วนขยาย)
เมื่อฮีโร่ที่อยู่ในเกมเป็นการ์ดมาสเตอร์ ให้ใช้ปุ่ม Z/X/C เพื่อเลือกการ์ดสีน้ำเงิน/แดง/เหลืองโดยอัตโนมัติ

![pickCards](https://github.com/user-attachments/assets/df5aa45a-8593-44c9-8c3f-bec315552113)

>ฟังก์ชันนี้ใช้งานโดยใช้การประมวลผลกราฟิกและการจำลองแป้นพิมพ์ โดยจะทดสอบเฉพาะความละเอียดที่ใช้กันทั่วไป 2 ความละเอียดเท่านั้น (1920x1080/2560x1440) ความละเอียดอื่นๆ ไม่สามารถใช้งานได้ตามปกติหากไม่มีการกำหนดค่าด้วยตนเอง (โดยเฉพาะความละเอียดอื่นนอกเหนือจากอัตราส่วนสเกล 16:9) การตรวจจับอนุญาตให้มีช่วงตัวกรองที่แน่นอน แต่ขอแนะนำว่าอย่าเปิดตัวกรองเมื่อใช้ฟังก์ชันนี้ เพื่อหลีกเลี่ยงไม่ให้การตรวจจับบางอย่างเป็นโมฆะ

## เริ่มต้นใช้งาน

### 1.เตรียมเจ้าภาพ
ดาวน์โหลด `LOLAutomationTools` (≥ 2.9.801) จาก [หน้าเผยแพร่อัปสตรีม] (https://github.com/Seraph1ne/LOLAutomationTools/releases) และแตกไฟล์ไปยังไดเร็กทอรีใดๆ ซึ่งจะถูกบันทึกเป็น `<宿主目录>` ด้านล่าง
พื้นที่เก็บข้อมูลนี้ **ไม่ได้แจกจ่าย** โปรแกรมโฮสต์

### 2. ดาวน์โหลดโมเดลคำพูด
VoiceModule ต้องใช้โมเดล ASR ในรูปแบบ sherpa-onnx (ประมาณ 254 MB) พื้นที่เก็บข้อมูลนี้ **ไม่แจกจ่าย** โมเดล สำหรับที่อยู่การดาวน์โหลดและเค้าโครงไดเร็กทอรี โปรดดูที่ [voice-module/README.md → Model Download](voice-module/README.md#模型下载)

### 3. การติดตั้งเพียงคลิกเดียว
ดำเนินการ (PowerShell) ในไดเรกทอรีรากของคลังสินค้านี้:
```powershell
.\scripts\install.ps1 -HostDir <宿主目录> -ModelDir <解压好的模型目录>
```
ตัวเลือก:
```powershell
-WithOpgg -SeraphineDir <Seraphine 目录>    # 同时安装 OP.GG launcher
-VoiceZip <本地 zip>                          # 离线安装，跳过下载
```
สคริปต์จะทำงานโดยอัตโนมัติ: ดาวน์โหลด Release `VoiceModule-latest.zip` → หยุดโฮสต์ → คัดลอก dll/pdb → เขียน `exe.config` (มีอยู่โดยไม่มีการเขียนทับ) → วางการกำหนดค่าเริ่มต้นไปที่ `Extend/` (มีอยู่แล้วโดยไม่ต้องเขียนทับ) → คัดลอกโมเดล

### 4. เปิดใช้งาน
เปิด `LOLAutomationTools.exe` → **ฟังก์ชั่นเพิ่มเติม** ทางด้านซ้าย → **เสียง** การจัดกลุ่ม → เปิดสวิตช์ **เสียงเป็นข้อความ** กด `空格` ค้างไว้เพื่อพูด ปล่อยเพื่อส่งไปที่แชทของทีม
